# Stable knowledge data

`shanghai_stable.jsonl` 是上海 MVP 的稳定知识编辑种子，用于验证 RAG 契约和体验语义召回。

每行是一条 JSON 文档，核心字段包括 `poi_id`、`summary`、体验/文化/建筑标签、适合与不适合条件，以及 `source`、`source_version`。新增内容必须：

1. 只写相对稳定的历史、文化、建筑和体验特征。
2. 不写“当前开放”“现在不拥挤”“今天可预约”等实时结论。
3. 与结构化 POI 使用相同 `poi_id`。
4. 保留可追踪的来源和版本；生产内容应替换编辑种子为经核验来源。

营业时间、坐标和类别进入结构化库；天气、拥挤、预约和交通通过实时工具接口获取。
